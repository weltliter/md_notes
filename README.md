## 标题
标题的书写方式是使用 `#` 号，`#` 的数量决定标题的层级（共有一到六级）。

**语法展示：**
# 一级标题
## 二级标题
### 三级标题

## 字体格式
Markdown 可以使用以下几种字体标识，符号需要将其包裹起来：

* **斜体**：用1个星号 `*` 包裹表示，如 `*斜体*`
* **粗体**：用2个星号 `**` 包裹表示，如 `**粗体**`
* **粗斜体**：用3个星号 `***` 包裹表示，如 `***粗斜体***`

## 分隔线
可以在一行中用三个以上的星号 `*`、减号 `-`、底线 `_` 来建立一个分隔线，行内不能有其他东西，也可以在星号或减号中间插入空格。下面这几种写法都可以建立分隔线：

***
* * *
******
- - -
------

## 删除线与下划线

* **删除线**：如果段落上的文字要添加删除线，只需要在文字的两端加上两个波浪线 `~~` 即可。
  * 语法：`~~带有删除线的文字~~`
  * 效果：~~带有删除线的文字~~
* **下划线**：Markdown 原生不支持下划线，但可以通过 HTML 的 `<ins>` 标签来实现。
  * 语法：`<ins>将被加下划线</ins>`
  * 效果：<ins>将被加下划线</ins>

## 列表
Markdown 支持有序列表和无序列表。符号和文字之间**必须加上一个空格字符**。

### 无序列表
无序列表使用星号 `*`、加号 `+` 或者减号 `-` 作为标记：
* 第一项
* 第二项

### 有序列表
有序列表直接在文字前加上数字和英文句号 `1.` `2.` `3.` 来表示：
1. 第一项
2. 第二项
3. 第三项

### 列表嵌套
列表嵌套只需在子列表的选项前添加一个制表符（Tab）或四个空格即可：
1. 第一项：
    - 第一项嵌套的第一个元素
    - 第一项嵌套的第二个元素
2. 第二项：
    - 第二项嵌套的第一个元素
    - 第二项嵌套的第二个元素

## 区块引用
区块符号 `>` 放在段落首位，`>` 的数量代表层级嵌套。

### 区块和区块中使用列表
> 区块中使用列表：
> 1. 第一项
> 2. 第二项
> 
> 无序列表嵌入：
> * 第一项
> * 第二项
>
> 列表中也可以嵌入区块，只需在列表项下方使用 `>` 即可。

## 代码块
可以用三个反引号包裹一段多行代码，并在第一排的反引号后侧指定一种编程语言（也可以不指定，以实现高亮效果）：

```javascript
document.read(function(){
    alert('Markdown');
});
```

## 链接
链接使用方法如下：

\[链接名称\]\(链接地址\)
或者
\<链接地址\>
例如：

这是一个链接 [新浪新闻](https://news.sina.com.cn/)

或者<https://news.sina.com.cn/>

## 图片
Markdown图片语法格式为：

\!\[alt 属性文本\]\(图片地址\)

\!\[alt 属性文本\]\(图片地址 "可选标题"\)

## 表格
Markdown制作表格使用|来分隔不同的单元格，使用-来分隔表头和其他行。

语法格式：

\|表头1\|表头2\|

\|----\|----\|

\|单元格11\|单元格12\|

\|单元格21\|单元格22\|

|表头1|表头2|
|----|----|
|单元格11|单元格12|
|单元格21|单元格22|

可以设置表头的对齐方式：

-: 设置内容或标题栏右对齐
:- 设置内容或标题栏左对齐
:-: 设置内容或标题栏居中对齐

## 数学公式

当你需要在编辑器中插入数学公式时，可以使用两个美元符 \$\$ 包裹 TeX 或 LaTeX 格式的数学公式来实现。

示例如下：

```
$$
\int_0^1 {x^2} \,{\rm d}x 
$$
```

显示效果： 

$$\int_0^1 {x^2} \,{\rm d}x$$
